## Why This List

Local LLMs let you run AI models on your own computer with privacy, no per-token cost and offline access. This list keeps it simple: 23 local LLM tools worth trying first, grouped by job, one line each.

## Contents

- Run Models Locally - 9 tools to run models on your own computer
- Serve and Chat - 7 tools to serve models and chat with them
- Local Coding and Helpers - 7 tools for coding and picking the right model

## Run Models Locally

| Tool | What it does |
| --- | --- |
| [Ollama](https://ollama.com/) | Run LLMs locally with one command and call them from your apps |
| [llama.cpp](https://github.com/ggml-org/llama.cpp) | Fast C/C++ engine for running LLMs locally on CPU and GPU |
| [LM Studio](https://lmstudio.ai/) | Desktop app to discover, download and chat with local LLMs |
| [Jan](https://github.com/janhq/jan) | Open source desktop app to run LLMs offline on your computer |
| [GPT4All](https://github.com/nomic-ai/gpt4all) | Run local LLMs privately on everyday desktops and laptops |
| [LocalAI](https://github.com/mudler/LocalAI) | Open source local AI server compatible with the OpenAI API |
| [KoboldCpp](https://github.com/LostRuins/koboldcpp) | Easy local LLM runner with a built in chat interface |
| [Project Maya](https://github.com/mw00/project-maya) | Runs very large MoE models on your own NVIDIA or AMD GPUs with browser chat and compatible APIs, free and open source |
| [AI:GO](https://go.backend.ai/) | Runs LLMs locally on your own PC in a desktop app and headless server with an OpenAI-compatible API - free, Apache 2.0, no account needed |

## Serve and Chat

| Tool | What it does |
| --- | --- |
| [vLLM](https://github.com/vllm-project/vllm) | High throughput serving engine for running LLMs on GPUs |
| [SGLang](https://github.com/sgl-project/sglang) | Fast serving framework for large language and multimodal models |
| [Open WebUI](https://github.com/open-webui/open-webui) | Self hosted web interface for chatting with local models |
| [AnythingLLM](https://github.com/Mintplex-Labs/anything-llm) | Local AI app to chat with your documents using local models |
| [TextGen](https://github.com/oobabooga/textgen) | Web interface for running and experimenting with local LLMs |
| [Cherry Studio](https://github.com/CherryHQ/cherry-studio) | Desktop AI client for local and remote models in one app |
| [Lemonade](https://github.com/lemonade-sdk/lemonade) | Local LLM server with GPU and NPU acceleration |

## Local Coding and Helpers

| Tool | What it does |
| --- | --- |
| [Continue](https://github.com/continuedev/continue) | Open source AI code assistant that can use local models |
| [Aider](https://github.com/Aider-AI/aider) | AI pair programming in your terminal with local model support |
| [Cline](https://github.com/cline/cline) | AI coding agent in VS Code that can run with local models |
| [llmfit](https://github.com/AlexsJones/llmfit) | Find which local models fit and run well on your hardware |
